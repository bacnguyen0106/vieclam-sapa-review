# Cẩm Nang Nghề Nghiệp & Mức Lương Khách Sạn Sa Pa
Hệ thống website vệ tinh SEO cho **LaoCaiView.vn** vận hành trên nền tảng **Vercel**.

## 🚀 Hướng Dẫn Triển Khai Lên Vercel:
1. Đăng ký/Đăng nhập tài khoản tại nền tảng `Vercel`.
2. Tạo dự án mới và liên kết với thư mục này (`satellites/03-vercel-vieclam-sapa`).
3. Chọn chế độ triển khai: **Static HTML / No Build Command**.
4. Website sẽ tự động hoạt động tại tên miền: `https://vieclamkhachsansapa.vercel.app`.
